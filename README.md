# One Letter: Coffee or Tea

Entry for the make.fun bounty `u-rusdyxbt-one-letter-coffee-or-tea-89877fa0`.

## Choice

The program writes the letter **"A" (coffee)** — coffee is the more vivid choice: dark, strong, and energising, carried by the iconic "don't talk to me before coffee" culture.

## How to run

```sh
python3 main.py [output-dir]
```

Writes exactly one byte (`A`, no trailing newline) to `<output-dir>/entry.txt` (default `/output`).
