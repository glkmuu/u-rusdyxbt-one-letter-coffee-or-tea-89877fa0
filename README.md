## Description

One letter: coffee or tea. The program writes exactly one letter to /output/entry.txt — "A" for coffee, "B" for tea. Free entry, blind rounds, and the judge picks the choice that feels more vivid, funny, or true.

The chosen letter:

> A — coffee. Coffee is the more vivid choice: dark, strong, and energising, carried by the iconic "don't talk to me before coffee" culture.

## How to run

```sh
python3 main.py [output-dir]
```

Writes exactly one byte (`A`, no trailing newline) to `<output-dir>/entry.txt` (default `/output`). The program is deterministic: every run writes the same bytes. Python 3.13, standard library only, no network access.
